# 功能清单（版本沿革）

本插件围绕「多渠道免费积分的自动领取与可视化治理」逐步演进，按版本列出功能点。
协议细节与踩坑记录见根目录 [MEMORY.md](../MEMORY.md)。

## v0.1 – v0.2（2026-11 前）

- [x] 三渠道每日签到：`buddy`（CodeBuddy 中国版）/ `workbuddy` / `codearts`（华为云）
- [x] 启动后 15s 自动跑一轮（`DSH_CODEARTS_AUTO_CHECKIN_DELAY_MS` 可调）
- [x] 结果挂 `/api/codearts-checkin`，只做签到，不注册 LLM 适配器、不改凭据

## v0.3.0（2026-11-04）浏览器半身

- [x] 新增 `client.js`：设置页注册「签到」页（排在 WorkBuddy 之后）
- [x] 展示三渠道每个账号的签到状态与额度
- [x] 「立即签到」「刷新」按钮

## v0.4.0（2026-11-04）账号管理

- [x] 设置页内账号清单：新增 / 删除 / 启用停用
- [x] CodeBuddy 扫码登录（`lib/buddy-login.js`）
- [x] 多账号池（`orderPool` 轮转），签到覆盖所有账号

## v0.5.0（2026-11-04）CodeArts 页面内登录

- [x] CodeArts AK/SK 登录入口，token 自动刷新
- [x] ⚠️ 确认 refresh_token 为一次性：刷新即作废，跨设备共用会互踢

## v0.6.0（2026-11-04）模型渠道

- [x] 注册 `devcloud/*` provider，DSH 对话可直走 CodeArts 模型
- [x] 额度为积分制；并发会话上限 3（按账号）
- [x] 模型清单以服务端为准，动态拉取

## v0.6.1（2026-11-04）DSML 工具通道

- [x] DSML 工具调用协议支持（`lib/dsml.js`）
- [x] 并发上限实测修正与排队等待计划（`QUEUE_WAIT_PLAN_MS`，默认 3/9/20 秒）

## v0.6.2（2026-11-04）会话治理 + 剩余积分

- [x] 排队状态查询（`/api/v1/queue/status?task_id=`）
- [x] 每账号并发闸门（`lib/sessions.js`，默认 3 路）、在途登记
- [x] 主动终止会话（abort 前先置 `phase='aborting'`，异常路径断流防「越用越卡」）
- [x] 终止后 45s 冷却（服务端无会话列表/关闭接口的补偿方案）
- [x] 会话界面显示剩余积分（`statistics/plugin` 的 `metrics`）

## v0.6.3（2026-11-04）重复账号判重

- [x] 身份解析（`lib/identity.js`）：refresh_token JWT → `account_id`
- [x] 账号池按 `identityKey` 去重（AK/SK 不同但同一账号只算一个）
- [x] 重复账号标记（`lib/duplicates.js`）

## v0.6.4（2026-11-04）首屏性能 + 全渠道余额

- [x] 状态缓存 + 有界并发探测（`mapLimit`），首屏加载显著提速
- [x] 腾讯系余额查询（`/v2/billing/meter/get-user-resource`），CodeBuddy 精确积分
- [x] CodeArts 资源包余量按包聚合显示，无 K 缩写
- [x] CodeBuddy 积分失败不拖垮签到状态展示

## 跨设备同步包（v0.6.4 附加，2026-11-05）

- [x] `tools/make-sync.mjs`：打包插件源码 + 账号配置（`--no-credentials` 可去凭据、`--plugin-only` 打纯插件包）
- [x] `tools/install-sync.mjs`：合并式安装（账号按 id 合并、凭据按引用名补缺、原文件先备份）
- [x] 真 zip 产物（System32 bsdtar），资源管理器可直接解压

## v0.6.5（2026-11-06）提示误导修复

- [x] 刷新按钮强制绕过缓存（`load(true)`），清过期提示
- [x] 提示按时间相对化显示、按 warn/error/info 分级配色
- [x] 修复渲染桩重复调用函数组件导致的 hook 计数错乱
